⚡
Quick Start
  1. Make sure Ollama is running: ollama serve
  2. Pull the model: ollama pull qwen2.5-coder:3b
  3. Create a Project with your site URL
  4. Click AI Discovery to auto-generate test cases
  5. Click Run All to execute the full test suite

        
🕵️
Tech-Audit
  1. Tests capture Browser Console Errors automatically
  2. Hidden Network Failures (4xx/5xx) are flagged
  3. A test FAILS if technical errors occur, even if UI looks correct
  4. View details in the "Tech Logs" tab of any result

        
📱
Mobile Emulation
  1. Use the Device Switcher in the Workspace header
  2. Choose Desktop, Mobile (iPhone 13), or Both
  3. Both mode runs tests sequentially on each device
  4. Touch events are simulated for mobile

        
🛠
Auto-Healing
  1. When a selector breaks, AI analyzes the live DOM
  2. Finds the best alternative selector automatically
  3. Permanently updates the test case in database
  4. Tests stay valid even after site redesigns

        
▶
Run Tests
  1. Select a test case from the dropdown
  2. Choose Graph mode (recommended, faster)
  3. Click Run — AI controls Chrome via Playwright
  4. Watch live terminal + step-by-step results

        
🔄
Regression Testing
  1. Open a project → click Run All
  2. Tests run sequentially with live progress
  3. Queue shows current test + completion count
  4. View consolidated pass/fail/adapted results

        
🧩
Chrome Extension
  1. Open chrome://extensions in Chrome
  2. Enable Developer mode
  3. Click Load unpacked → select chrome-extension/
  4. Navigate to site → click extension → Start Recording
  5. Save recorded flow to project instantly

        
📊
Status Meanings
PASS — Step executed as expected
ADAPTED — AI found alternative approach
FAIL — Step failed or tech error detected
BLOCKED — Could not execute (site down)
